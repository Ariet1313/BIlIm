# Бийик

Сайт для школьников Кыргызстана: олимпиады, программы и стипендии, research и истории успеха.

## Как открыть
Дважды кликни на `index.html` — сайт откроется в браузере. Сервер не нужен.

## Структура
- `index.html` — главная
- `guide.html` — как поступить (шаги, словарь, страны, мифы, FAQ)
- `olympiads.html` — олимпиады с фильтром и поиском
- `programs.html` — программы и стипендии
- `research.html` — как начать исследование + доска проектов
- `stories.html` — истории успеха и цитаты
- `about.html` — о проекте и авторе
- `js/config.js` — **твои настройки**: данные об авторе и подключение базы
- `js/data-ky.js` — кыргызский перевод данных (тот же порядок, что в data.js)
- `img/ariet.jpg` — фото автора
- `js/data.js` — **все данные сайта**. Чтобы добавить олимпиаду или историю, допиши объект в нужный список.
- `js/main.js` — логика, шапка, подвал, орнаменты (тундук, кочкор мүйүз)
- `css/style.css` — стиль

## Данные
Все факты собраны ИИ из открытых источников (официальные сайты, imo-official.org, 24.kg, kaktus.media и др.).
У каждого факта есть ссылка на источник. Последняя проверка — 19 октября 2026.
Сроки программ меняются каждый год, поэтому данные нужно обновлять.

## Добавление записей посетителями
В каждом разделе есть кнопка «+ Добавить»: олимпиаду, вуз или программу, историю успеха, research-проект.
К каждой записи (кроме проекта) нужна ссылка на источник, и она отмечается как «Добавлено сообществом».

Пока база не подключена, запись сохраняется только в браузере того, кто её добавил.

## База данных (чтобы добавленное видели все) — бесплатно, 10 минут
1. Зарегистрируйся на https://supabase.com и создай проект.
2. Открой **SQL Editor** и выполни:

```sql
create table submissions (
  id bigint generated always as identity primary key,
  created_at timestamptz default now(),
  type text not null check (type in ('olympiad','program','story','project')),
  data jsonb not null,
  approved boolean not null default false
);
alter table submissions enable row level security;
-- все видят только одобренные записи
create policy "read approved" on submissions for select using (approved = true);
-- любой может отправить запись; проекты сразу видны, остальное — после проверки
create policy "submit" on submissions for insert
  with check (approved = false or type = 'project');
```

3. В **Project Settings → API** скопируй `Project URL` и `anon public key` и вставь их в `js/config.js`.
4. **Модерация:** в **Table Editor → submissions** проверь запись (открой ссылку-источник) и поставь `approved = true`. После этого её увидят все.

## Языки
Переключатель РУС / КЫР в шапке. Статичный текст страниц хранится в атрибутах `data-ky`, данные — в `js/data-ky.js`.
