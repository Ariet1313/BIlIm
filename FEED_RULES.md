# Правила ленты «Бийик» (для ИИ-редактора)

Лента хранится в `js/feed.js` в формате:

```js
window.FEED = { "updated": "YYYY-MM-DD", "items": [ ... ] };
```

## Формат записи
```json
{
  "id": "2026-10-27-korotkoe-latinicej",      // уникальный, латиница, дефисы
  "type": "news | opp | uni | fact",          // новость, возможность, вуз, факт
  "date": "YYYY-MM-DD",                       // дата события/публикации источника
  "expires": "YYYY-MM-DD",                    // только для opp (дедлайн); у остальных можно не указывать
  "emoji": "🎓",
  "title": { "ru": "...", "ky": "..." },      // до ~70 символов
  "text":  { "ru": "...", "ky": "..." },      // 1–3 предложения, до ~300 символов
  "source": { "name": "24.kg", "url": "https://..." }
}
```

## Что публиковать
- **news** — новости об образовании для школьников Кыргызстана: медали олимпиад, поступления, новые гранты и квоты, решения Минобразования.
- **opp** — открытые возможности с понятным дедлайном: стипендии, программы обмена, летние школы, конкурсы, олимпиады для школьников (лучше доступные гражданам КР).
- **uni** — короткий профиль вуза: чем полезен школьникам из КР (стипендии, финпомощь иностранцам, программы на английском).
- **fact** — интересный проверяемый факт, который мотивирует (результаты, цифры, истории).

## Строгие правила
1. Каждый факт берётся из источника, который ИИ сам открыл и прочитал в этот день. Ничего не выдумывать.
2. Источник — официальный сайт или уважаемое СМИ (24.kg, Kaktus.media, AKIpress, Kloop, сайты вузов, программ, олимпиад). Не агрегаторы стипендий.
3. Цифры и даты — ровно как в источнике. Если дедлайн неизвестен — не ставить `opp`.
4. Тексты на русском и кыргызском, простым языком для школьника.
5. Без личных данных сверх того, что опубликовано в источнике; без фото.
6. Не дублировать уже существующие записи (сверять по смыслу и `id`).

## Удаление
- Удалять `opp`, у которых `expires` уже прошёл.
- Удалять `news` старше 60 дней.
- Держать в ленте не больше 60 записей (удалять самые старые `news`/`fact`).
- Удалять записи, если источник больше не подтверждает информацию.
